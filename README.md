# 💪 Strength Survival Discord Bot

A custom Discord bot made for the Strength Survival Minecraft SMP community.

## 📌 Features
- Staff commands (view staff list)
- Server information commands
- Rules command
- Welcome messages
- Moderation tools (kick, ban, mute - if enabled)

## 🚀 Setup / Installation

1. Install Python 3.10+
2. Install dependencies:
```bash
pip install discord.py
